# Privacy

Domain Guardian processes navigation URLs on the device. It does not send browsing history, domains, page content, or configuration to any server. It has no analytics, accounts, cookies, or remote-code loading.

Custom protected domains are saved in browser-local extension storage until removed or the extension is uninstalled. Warning URLs contain only the flagged hostname, not the original path, query, or credentials. Browser history may retain extension warning URLs according to browser behavior. Opening a suggested protected-domain link makes a normal browser request to that site.

The extension requires navigation, tab, and storage access for automatic checks, warning redirects, current-tab inspection, and local settings. It does not read page content.
