Installation details & important limits +

Open chrome://extensions or edge://extensions. Turn on Developer mode, click Load unpacked, select the extracted extension folder, then pin Domain Guardian.

This prototype flags single-edit typos, deceptive domain structures, selected visual substitutions, and internationalized names. It includes 15 protected domains and lets you add your own.

Warnings happen after navigation begins. A match does not verify page content, and an unknown domain is not necessarily safe. False positives and missed threats are possible. Browser acceptance testing is still pending; Firefox and mobile are not supported.

The extension uses navigation, tab, and local storage access. Analysis stays on-device. It does not read page content or send browsing history to a server.
