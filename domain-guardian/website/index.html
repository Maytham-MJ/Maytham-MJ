A TOOL, NOT A GUARANTEE

Good security starts with honest limits.

Domain Guardian is an open-source prototype. Warnings happen after navigation begins, so it cannot guarantee that a page has not loaded. A protected-domain match does not verify page content, and unfamiliar phishing domains can go undetected. Legitimate domains may trigger warnings.

What does the extension have access to?

Navigation and tab URLs for checking addresses and showing warnings, plus local storage for custom domains. It does not read page content or send browsing data to a server.

What if a legitimate site gets flagged?

Check the address independently. This prototype has no one-click bypass. If you choose to proceed, use your browser’s extension manager to disable it for that visit, then re-enable it afterward.

Can I use it on Firefox or mobile?

This version targets desktop Chrome and Edge. Firefox and mobile support have not been implemented or tested.

How has it been tested?

The extension has 28 passing local automated tests covering detection and a mocked navigation flow. Real-browser acceptance testing is still pending. No measured detection accuracy or prevention rate is claimed.
